# Emerging Technologies Assessment — Classical vs Quantum Algorithms (Deutsch / Deutsch–Jozsa)

4th year module in ATU Galway 25/26

This repository contains my solutions for the **Emerging Technologies (Summer 25/26)** assessment.  
The work focuses on the contrast between **classical** and **quantum** query complexity using:

- Random constant/balanced Boolean functions (4-bit input)
- A classical decision procedure
- Quantum oracles for Deutsch’s problem (1-bit input)
- Deutsch’s algorithm (Qiskit)
- Deutsch–Jozsa algorithm for 4-bit functions (Qiskit)

## Repository contents

- `problems.ipynb` — primary submission notebook with all problems solved
- `requirements.txt` — Python dependencies
- `.gitignore` — ignores local/temporary files
- `data/` — (reserved) datasets (not used unless stated)
- `img/` — (reserved) figures generated by the notebook
